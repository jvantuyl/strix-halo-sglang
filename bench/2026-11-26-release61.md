### Reproducing the native prefix check

Use `/generate` with `input_ids` set to
`random.Random(1771).choices(range(256, 12000), k=1985)` from Python.
Set `temperature=0`, `sampling_seed=1234`, `ignore_eos=true`, and
`max_new_tokens=24` inside `sampling_params`. Use two fresh top-level
`cache_salt` values in the order A, B, A. Record `output_ids`,
`meta_info.cached_tokens` and `meta_info.spec_verify_ct` for each request.
No cache flush is needed. Compare all token IDs and prefix counts, not
just the rendered text or the fact that the request succeeded.

Run this check on each image with the same context length, KV pool,
attention backend and target/draft configuration. A repeat that reports
no cache hit has not tested cached decoding.
